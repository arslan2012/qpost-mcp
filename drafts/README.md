# Drafts

Ready-to-post replies produced by the daily `qpost-growth-ops` task.

The task runs headless and **cannot post to Reddit** — it finds threads and
writes drafts here. Read one, edit if you disagree with it, then post it
yourself (or ask in an interactive session and it'll be posted for you).

Filename format: `YYYY-MM-DD-<subreddit>-<slug>.md`, thread URL on line 1.

Delete a draft once it's posted, and it gets recorded in
`growth-ops-state.json` under `reddit_posts` so the same thread is never
surfaced twice.
